# X Mobile Profile UI

A responsive React and TypeScript recreation of an X (formerly Twitter) mobile profile and post screen. The demo includes profile details, follower statistics, a post feed, interactive like and repost buttons, bookmark behavior, and feedback toasts.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Build the project with `npm run build`.

This is a front-end interface demo. It does not connect to X or change any real account data.
